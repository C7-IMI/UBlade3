# Exactness contract

UBlade3 is an **exact clone** in the sense that every ported subsystem maps to a decompilation function and is
checked against the game's own data or the 20XX reference where possible. The following rules apply:

- Original data files are read in their original encoding and field order.
- Any unit conversion is documented next to the loader and tested.
- A ported C# function cites its decomp file and address (or nearest symbol).
- A function is only marked ported when a test or parity check exists.
- Placeholder art may be used only as an explicit temporary bootstrap; it must be labelled and must not be
  committed as if it were the original asset.

The `PortLedger` generated by `tools/port/generate_ledger.py` is the source of truth for coverage.
